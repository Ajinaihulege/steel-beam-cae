# 典型钢结构受力性能自动化分析集成

## 1. 作品概述

本作品以 HW200×200×8×12 工字钢为对象，在炎核 CAX 高效智能重构平台中完成从几何模型、网格划分、静力求解到云端后处理显示的自动化流程。

技术路线为：

```text
HW200×200×8×12 STP 模型
        ↓
GmshAdapter 自动网格划分
        ↓
CalculixAdapter 静力求解
        ↓
Dime2.0 云端后处理显示
```

作品重点在于验证重构平台的多组件协同能力，实现输入模型、网格、求解和后处理之间的数据自动传递。

## 3. 几何与工况

- 截面形式：HW200×200×8×12 工字钢
- 模型长度：4000 mm
- 网格类型：一阶四面体网格（C3D4）
- 网格尺寸：10 mm
- 材料：Q235B
- 弹性模量：206000 MPa
- 泊松比：0.3
- 密度：7.85×10⁻⁹ t/mm³
- 左端下翼缘底面：固定约束
- 右端下翼缘底面：Y、Z 向约束
- 跨中顶面：竖向总荷载 20 kN

## 4. 网格与模型信息

`HW200x200x8x12_mesh_10mm.inp` 中已经包含：

- 节点坐标

- 截面与单元集合
- 固定约束和滚动约束

- 位移、反力、应力和应变输出设置

主要规模为：

- 节点数：54946
- C3D4 单元数：165508

## 5. 重构平台运行方法

1. 打开炎核 CAX 高效智能重构平台。
2. 确认 `GmshAdapter`、`CalculixAdapter` 和 `Dime2.0` 插件已经加载。
3. 进入平台的任务流/脚本执行入口。
4. 导入或执行 `钢钢的好工字梁.py`。
5. 任务流将依次执行以下三个节点：

```text
A1 网格生成
A2 计算求解
A3 显示后处理界面
```

6. 等待三个节点全部显示完成。
7. Dime2.0 页面加载后，在模型树中查看工字钢结果，并选择应力或位移云图。

注意：`钢钢的好工字梁.py` 是重构平台导出的任务流调用脚本，不是可以脱离平台直接运行的普通 Python 程序，不应使用命令行 `python 钢钢的好工字梁.py` 单独执行。

## 7. 注意事项

导出的任务流脚本中包含平台生成的资源 UUID 和本机绝对路径。该脚本用于记录和复现当前平台工作流；在其他电脑上执行时，可能需要重新导入 STP 文件，并重新绑定对应的插件和资源。

如果评审环境没有相同的资源记录，应以 README 中的参数和 INP 文件为依据，在平台中重新创建同一工作流。
