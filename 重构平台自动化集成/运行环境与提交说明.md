# 运行环境与提交说明

## 软件环境

- 操作系统：Windows 10/11 64 位
- 平台：炎核 CAX 高效智能重构平台 2.0.14
- 前处理组件：GmshAdapter
- 网格内核：Gmsh 4.11.1
- 求解组件：CalculixAdapter
- 后处理组件：Dime2.0

## 插件与接口

- 网格生成接口：`PreprocessingMeshSolidCommand`
- 求解接口：`SimulatorRunSolverCommand`
- 后处理接口：`PostprocessingShowFormCommand`

## 平台工作流

```text
A1 网格生成
    ↓
A2 计算求解
    ↓
A3 显示后处理界面
```

工作流包含 3 个节点和 4 条边：

- 2 条执行顺序连接
- 2 条文件数据传递连接

## 提交注意事项

1. 演示视频需要清楚展示完整工作流的运行过程。
2. 演示视频需要包含 Dime2.0 模型加载和云图显示过程。
3. `钢钢的好工字梁.py` 是平台任务流脚本，不是独立 Python 程序。
4. 如使用另一台电脑复现，需要重新导入 STP 并绑定平台资源。
5. `HW200x200x8x12_mesh_10mm.inp` 可以作为不依赖平台资源记录的网格和工况参考文件。
