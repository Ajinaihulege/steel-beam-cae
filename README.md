# 典型钢结构受力性能仿真与分析

## 项目概况

本项目基于炎核CAX平台分析一根简支工字钢梁在跨中竖向荷载作用下的静力响应。

| 项目 | 参数 |
|---|---|
| 截面 | HW200×200×8×12 |
| 梁长 | 4000 mm |
| 材料 | Q235B |
| 弹性模量 | 206000 MPa |
| 泊松比 | 0.3 |
| 总荷载 | 20 kN，方向 -Z |
| 边界条件 | 左端下翼缘底部固定 Ux/Uy/Uz；右端下翼缘底部约束 Uy/Uz |
| 单元类型 | 四面体实体单元 |

## 目录结构

```text
工字钢梁10mm网格/
├─ 前处理/   CAE 模型、STEP、网格脚本和 INP
├─ 求解/     VTU/PVD 求解结果
└─ 后处理/   位移、应力、主应力云图

工字钢梁15mm网格/
├─ 前处理/
├─ 求解/
└─ 后处理/
```

## 主要文件

- `.ncti`：CAE 前处理模型
- `.stp`：三维几何模型
- `*_网格剖分脚本.py`：平台自动化网格脚本
- `ncti.inp`：求解器输入文件
- `ncti_vtu.pvd` / `ncti_vtu_subcase1.vtu`：后处理结果
- `*.png`：结果云图

## 结果对比

| 网格尺寸 | 最大竖向位移 | 跨中下翼缘弯曲应力 | 说明 |
|---|---:|---:|---|
| 15 mm | 约 3.045 mm | 约 43.7 MPa | 粗网格 |
| 10 mm | 约 3.041 mm | 约 43.9 MPa | 主结果 |

理论参考值：

```text
跨中挠度：约 2.81 mm
跨中最大弯曲应力：约 43.4 MPa
```

15 mm 与 10 mm 两次结果的跨中挠度和弯曲应力变化均小于 1%，可认为网格已经收敛。

## 打开方式

- CAE 前处理：打开对应目录中的 `.stp`
- 后处理：打开 `ncti_vtu`
- 求解器输入：查看 `ncti.inp`

## 说明

结果中的局部最大 Mises 应力通常位于支座或加载点附近，受局部约束和网格影响。评价梁的整体弯曲性能时，建议使用跨中下翼缘的轴向弯曲应力 `Sxx` 和跨中竖向位移 `Uz`。
